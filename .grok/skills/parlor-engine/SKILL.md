# Движок Parlor

Продуктовое решение и гейт смены движка — в `docs/PLAN.md`, разделы «Движок» и «Гейт движка». Здесь только то, что нельзя ослабить в коде.

## Что ставить

Первая версия рендерит страницы системным `android.webkit.WebView`. Свой Chromium, Cromite, Brave или GeckoView не подключать, пока в плане нет датированного решения по гейту. Аргумент «так надёжнее на приставке» гейт не заменяет.

Страницу загружает процесс телевизора. Не проксировать HTML и медиа через телефон.

## WebView

- JavaScript включён. Доступ к файлам и content-провайдерам из страницы выключен. Смешанный контент запрещён.
- Геолокация, камера и микрофон не выдаются заодно с загрузкой страницы.
- `target=_blank` и `window.open` остаются вкладками Parlor.
- После смерти рендера показать ошибку и предложить последний адрес. Процесс UI не завершать вместе с рендером.
- При старте прочитать версию WebView. Ниже Chrome 110 оставить видимую пометку, что движок устарел. Порог не поднимать без новой записи в матрице устройств.

Пресеты агента: настольный по умолчанию на телевизоре, телефонный, системный. Настольный пресет — явная строка через API WebView, не дописывание суффикса к уже урезанной системной строке.

Wide viewport и overview mode включать. Масштаб страницы и масштаб текста хранить раздельно. Принудительную CSS-ширину не хардкодить: на части 4K-приставок `devicePixelRatio` равен 4, но это не универсальная константа. Если нужен обход, он включается настройкой после замера конкретного устройства.

## Видео

Полноэкранный HTML5 идёт через `onShowCustomView` / `onHideCustomView`. На полноэкранный вид накладывать системные отступы, иначе контролы прячутся у края.

Звук отдавать в медиасессию, чтобы play/pause пульта работал и после ухода с приложения звук можно было остановить.

Поток в Media3 / ExoPlayer переносить только по действию «открыть в плеере». Тихий перехват `.m3u8`, `.mpd` и файлов ломает плеер самой страницы. В плеер передать User-Agent, Referer и куки этой вкладки.

Уровень Widevine не менять и не обещать. Нет лицензии устройства — показать ошибку. Обход CDM не писать.

## Чего не делать в этой области

- Не тащить NDK, пока хватает Kotlin. Нативные библиотеки обязаны быть 64-бит и с выравниванием 16 КБ для Play.
- Не поднимать `minSdk` выше 24 ради удобства API, пока план держит старые приставки. Новый API прятать за проверкой версии.
- Не добавлять блокировщик рекламы «заодно»: он маскирует поломки сайтов на фазах 1–3.
