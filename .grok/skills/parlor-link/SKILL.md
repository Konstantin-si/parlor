# Связь Parlor

Спека режимов и состава сообщений — в `docs/PLAN.md`, раздел «Связь». Здесь правила канала.

## Кто кого слушает

Телевизор слушает. Телефон подключается. Страницу каждое устройство грузит само. Эндпоинта, который по просьбе телефона сходит на произвольный URL и вернёт тело, быть не должно. Картинку экрана телефона не слать.

Команды до подтверждения сопряжения не исполнять. Отладочный порт без ключа не оставлять даже за флагом сборки, который может уехать в release.

## Сопряжение

- QR содержит адрес, порт и одноразовый секрет. Секрет сгорает после успеха и при закрытии экрана сопряжения.
- Короткий код на экране — тот же обмен для телефона без камеры.
- Постоянный токен в картинке на главном экране не показывать.
- После успеха хранить ключ устройства. Повторное соединение без нового кода — норма.
- «Забыть телефон» удаляет ключ и рвёт сокет.
- Слушать только локальные интерфейсы. Чужой Host отклонять.

Кадр по Wi-Fi — WebSocket уже после ключа. Состояние телевизора (адрес, заголовок, загрузка, вкладки) слать событием. Опрос раз в несколько секунд не использовать как основной протокол.

## Bluetooth

BLE — поиск и те же короткие команды, когда TCP до телевизора не открывается. По BLE не слать снимок экрана, файл и медиа.

HID-профиль (`BluetoothHidDevice`) не использовать в фазах 1–6. Он зависит от производителя телефона и не несёт вкладок и адреса.

Если TCP не соединился, а интернет у телефона есть, сказать прямо: устройства в одной сети друг друга не видят (гостевая сеть или изоляция клиентов). Не подменять это бесконечным поиском. Не предлагать переносить телевизор в гостевую сеть.

VPN на телефоне проверять отдельно и писать про него своим текстом: значок Wi-Fi при этом может гореть.

## Что канал возит из данных сайта

Куки и localStorage копировать только у вкладки, которую сейчас ведут с телефона, только на сопряжённый телевизор, только по уже установленному каналу. Чужие вкладки не трогать. В облако и в логи это не писать. Пароли не синхронизировать. Тело страницы не копировать: каждое устройство грузит его само.

Ключ сопряжения не передавать в JavaScript страницы и не писать в логи.
