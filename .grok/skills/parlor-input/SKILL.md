# Ввод Parlor

Режимы и раскладка кнопок — в `docs/PLAN.md`, раздел «Ввод» и список режимов. Сессия страницы в режимах пульта, курсора, подсказок, очереди, плеера и читалки живёт на телевизоре. Телефон в этих режимах показывает адрес телевизора и шлёт команды.

## Пульт

- Back с страницы — история WebView. Выход из приложения только с пустой истории или с домашнего экрана.
- OK — щелчок в точке курсора, когда курсор включён. Удержание OK переключает курсор и стрелки и не активирует элемент под курсором.
- Стрелка, упёртая в край, листает то, что лежит под курсором, включая блок со своей прокруткой.
- Адрес открывается с телефона и локальным жестом. Не требовать кнопку Menu: на части пультов её нет.
- Пространственную навигацию Blink не делать единственным способом ходить по странице. Ловушки фокуса в TV WebView известны. Курсор и подсказки должны работать без неё.

Фокус оболочки рисовать так, чтобы его было видно с дивана. Мелкий телефонный фокус на телевизор не переносить. Отступ под overscan — выключенная настройка, не постоянное поле 5%.

## Телефон

В режиме пульта большая часть экрана — трекпад. Касание — левый щелчок, два пальца — прокрутка, долгое касание — правый. Цели кнопок вокруг трекпада не меньше 44×44 px.

Клавиатура — системная клавиатура телефона. Текст в поле страницы вставлять так, чтобы сработали `input` и `change`, а не только присваивание `value`. Иначе поля React и Vue остаются пустыми для самого сайта.

Адресная строка режима «Отправить» принадлежит вкладке телефона. Не подписывать её так, будто это уже экран телевизора.

## Подсказки

Скрипт на странице собирает видимые ссылки и кнопки и рисует короткие метки. Выбор метки с телефона и с пульта вызывает тот же щелчок.

Скрипт не получает ключ канала. Мост в приложение — один метод, который принимает только тот отчёт, который нативный код только что запросил одноразовым номером. Метод не открывает сеть, не читает хранилище приложения и не принимает адрес для загрузки.

После прокрутки и после динамической подгрузки метки устаревают. Их надо пересчитать, а не оставлять на старых координатах.

Панель Parlor всегда открывается с телефона, даже если страница забрала фокус клавиатуры и стрелок.
