# Parlor

Канон продукта — [docs/PLAN.md](docs/PLAN.md). Порядок работ — [docs/CHECKLIST.md](docs/CHECKLIST.md). Пока фаза в чеклисте не открыта, код приложения не писать.

Скилы лежат в `.grok/skills/` и подхватываются в этом репозитории:

- `parlor-engine` — любой код WebView, видео, пользовательского агента, масштаба и выбора движка.
- `parlor-link` — сопряжение, сокет, Bluetooth, обнаружение, хранение ключа.
- `parlor-input` — пульт, курсор, подсказки по ссылкам, ввод текста, интерфейс телефона и телевизора.

Правила, которые легко нарушить мимо плана:

- Страницу загружает телевизор. Телефон не проксирует чужие сайты.
- Куки, пароли и localStorage между телефоном и телевизором не копируются.
- Секрет сопряжения не попадает в JavaScript страницы и не живёт в постоянном QR-коде на главном экране.
- Форк Chromium или Brave не начинается без записи в матрице устройств и явного решения по гейту из плана.
